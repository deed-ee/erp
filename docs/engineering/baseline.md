## Adoption decisions and checks

- Preserve accepted ADRs and existing gates. Use narrowly selected ESLint rules and unchanged production dependencies. ESLint/TypeScript-ESLint, Angular template lint (MIT) and Prettier (MIT, same version as the website) give errors the current compiler cannot; `@types/node` supplies independent browser-test tooling types. These are dev-only changes. Review transitive SPDX licenses/notices and npm advisories; lock versions and use `npm ci`. TS 7 from #79 is outside the installed type-checked lint compatibility range. Defer a full lint preset, checked scripts/styling beyond demonstrated violations, generated client, scaffold and broad refactors.
- Remove legacy formatting exceptions by touching individual files or after the high-conflict previews have landed. No source is mechanically reformatted in the foundation. New/edited files must pass and the fingerprint set cannot expand once adopted. Don't benchmark by weakening tests or scan rules.
- Application ruleset requires strict `audit`, `contracts`, `rust`, `compose`, PRs, thread resolution and no bypass actor in the inspected ruleset; required review count is zero, no enforced code owner. Other two repos protect against deletion/non-fast-forward only. GitHub reports secret scanning, push protection and Dependabot security updates enabled in all three repos. No repository settings changed. After evidence, add the aggregate and consider website/community `validate`, appropriate single-maintainer exceptions and CODEOWNERS only after real owners and backup reviewers agree. Do not invent owner teams or unilaterally impose an approving count the project cannot meet.
- Inspect the combined diffs on #120/#131 before integrating. Preserve the Preview receipt proofs, image gates and feature flags. Coordinate lint inheritance for new Preview crates and Prettier cleanup on feature-owned files. Resolve #132 separately, compare hosted fast/full and scheduled results, then consider making the aggregate required. Do not close or retarget #78 or change required settings without maintainer review.
