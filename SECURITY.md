# Security

There are no supported production releases. Run the bootstrap only on a trusted local machine with synthetic data.

Please report vulnerabilities privately using GitHub's **Report a vulnerability** option under the repository's Security tab if enabled. Otherwise use a private contact listed on the repository owner's profile. If no private channel is listed, use a public issue only to request a private contact, without disclosing any vulnerability details. Do not include production data or live secrets in reports. Provide affected revision, impact and safe reproduction details. The maintainer will coordinate triage, a fix and disclosure. See the [threat model](docs/architecture/threat-model.md) for current controls and gaps.
