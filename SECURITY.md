# Security

There are no supported production releases. Run the bootstrap only on a trusted local machine with synthetic data.

Please [report a vulnerability privately on GitHub](https://github.com/deed-ee/erp4us/security/advisories/new). Do not include production data or live secrets in reports. Provide affected revision, impact and safe reproduction details. The maintainer will coordinate triage, a fix and disclosure. See the [threat model](docs/architecture/threat-model.md) for current controls and gaps.
